# Profile: General

> A catch-all for structured multi-agent work that isn't cleanly implementation, review, or research. Start lean; add only the sections the task needs.

Use when none of the other three fit — e.g. a spec-writer sub-agent, a coordinator, or a mixed one-off.

## Fill the template

Template: `templates/teammate-prompt-general.md`. Required: identity, responsibility, tasks. Optional (include only what applies): skills/context, reference files, files owned, validation, communication.

## Final response

Report what was completed, anything changed or produced, what was validated, and any blockers.

**If the task edits files in an ownership boundary, use the `implementation` profile instead** — it carries the ownership-safety and resume machinery this lean profile omits.
