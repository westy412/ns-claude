# Implementation Steps: Setting Up the JV Co

> **When to read:** When moving from planning to action — solicitors, accountants, filings, and timeline.

---

## Phase 1: Professional Advisors (Weeks 1–2)

### Solicitor

Engage a **corporate solicitor with JV experience**. Given both founders have prior bad partnership experiences:

- Consider separate solicitors for each founder during negotiation
- Jointly instructed firm produces final drafts
- **Budget:** £15,000–£40,000 for SHA, Articles, and inter-company agreements
- Look for firms with specific 50/50 JV experience (not just M&A)

**What to brief them on:**
- The three-entity structure (JV Co + two operating companies)
- Cost reimbursement model (not licensing)
- Sovereign domain requirements
- Both founders' need for strong exit protections

### Chartered Accountant / Tax Advisor

Engage a **chartered accountant** (ideally with tax specialisation):

- **Budget:** £3,000–£8,000 for initial structuring advice
- Key questions for them:
  - Associated company rules impact on CT thresholds
  - Transfer pricing compliance (SME exemption verification)
  - Optimal salary/dividend mix for founder-directors
  - Employee profit share structure (cash bonus vs EMI)
  - VAT group registration feasibility
  - CIHC risk assessment

### Specialist (If Needed)

- **IP solicitor** if complex IP licensing between entities
- **Employment solicitor** if staff secondment arrangements are complex
- **Pension advisor** for auto-enrolment setup

## Phase 2: Heads of Terms (Weeks 2–4)

Before full legal drafting, agree heads of terms between founders:

### Must-Agree Items

| Item | Decision Needed |
|---|---|
| Shareholding split | 50/50 confirmed |
| Profit distribution | 30% employee pool / 35% each founder (confirm) |
| Founder salaries from JV Co | Amount for each (recommend £12,570 baseline) |
| Reserved matters list | Review and agree the full list |
| Deadlock mechanism | Mediation → valuation → buy-sell (confirm) |
| Valuation method | Independent valuation with EBITDA floor (confirm multiple) |
| Good/bad leaver definitions | Agree trigger events and consequences |
| Non-compete scope and duration | Agree carve-outs for operating companies |
| Lock-up period | 3–5 years |
| Cost reimbursement markup | 5–10% on operating company costs |
| Board composition | One director each, no casting vote |
| Dispute resolution | CEDR mediation → LCIA arbitration |
| Governing law | English law |

### Non-Binding but Important

- Annual budget process and timeline
- KPI framework
- Reporting obligations
- Delegated authority thresholds

## Phase 3: Legal Drafting (Weeks 4–10)

### Documents to Draft

| Document | Drafter | Priority |
|---|---|---|
| **Shareholders' Agreement** | Solicitor | Critical — longest document |
| **Bespoke Articles of Association** | Solicitor | Critical — filed at Companies House |
| **Services Agreement (Product Co → JV Co)** | Solicitor | High — governs cost reimbursement |
| **Services Agreement (Services Co → JV Co)** | Solicitor | High — governs cost reimbursement |
| **IP Licence (if applicable)** | Solicitor / IP specialist | If IP crosses entity boundaries |
| **Cost Sharing Agreement** | Accountant / Solicitor | Documents cost allocation methodology |
| **Operating Manual** | Founders (with solicitor review) | Non-binding governance guide |

### Review Process

1. Solicitor produces first draft
2. Each founder reviews with their own advisor (if separate)
3. Comments exchanged
4. Negotiation meeting (in person recommended)
5. Final drafts agreed
6. Execution

## Phase 4: Formation and Registration (Weeks 10–12)

### Companies House Incorporation

| Step | Action | Cost |
|---|---|---|
| 1 | Choose company name (check availability at Companies House) | Free |
| 2 | Prepare Form IN01 with bespoke Articles | — |
| 3 | Submit digital incorporation | £100 (standard) or £156 (same-day) |
| 4 | Receive Certificate of Incorporation | — |
| 5 | Register PSCs (both corporate shareholders as RLEs) | Included |
| 6 | Complete identity verification for all directors (ECCTA 2023) | — |

**SIC Code:** 64202 (Activities of holding companies, non-financial)

### HMRC Registrations

| Registration | Deadline | Notes |
|---|---|---|
| Corporation Tax | Within 3 months of starting to trade | Automatic notification from Companies House, but verify |
| PAYE/Employer | Before first salary payment | Register online at gov.uk |
| VAT | When turnover exceeds £90,000 (or voluntary registration) | Consider voluntary registration for input VAT recovery |
| Employment Allowance | Claim via first EPS (Employer Payment Summary) | £10,500 offset against employer NIC |

### Banking

- Open JV Co business bank account
- Set up payroll facility
- Set up inter-company payment mechanisms

### Pensions

- Register with auto-enrolment pension provider (e.g., NEST, Smart Pension)
- Set up contributions for director-employees
- Postponement option available for first 3 months

---

## Phase 5: Inter-Company Setup (Weeks 12–14)

### Execute Inter-Company Agreements

1. Sign Services Agreements between each operating company and JV Co
2. Sign Cost Sharing Agreement
3. Sign any IP licences
4. Set up inter-company invoicing (monthly recommended)
5. Ensure VAT invoices are compliant

### Transfer Pricing Documentation (If Non-SME)

- Prepare functional analysis for each operating company
- Document cost base and markup justification
- File transfer pricing policy document
- Review annually

### If SME (Most Likely Initially)

- Document SME status (employee count, turnover, balance sheet)
- Keep on file for each year-end
- Monitor growth against thresholds
- Prepare TP documentation proactively if approaching thresholds

## Phase 6: Ongoing Compliance

### Annual

| Task | Deadline | Responsible |
|---|---|---|
| File annual accounts | 9 months after year-end | Accountant |
| File CT600 corporation tax return | 12 months after year-end | Accountant |
| Pay corporation tax | 9 months + 1 day after year-end | JV Co |
| File confirmation statement | Within 14 days of anniversary | JV Co / Accountant |
| Review inter-company agreements | Year-end | Founders + Accountant |
| Agree annual budget | 60 days before year-end | Founders |
| Verify SME status | Year-end | Accountant |
| Review Employment Allowance eligibility | Start of tax year | Accountant |

### Monthly

| Task | Responsible |
|---|---|
| Management accounts for JV Co | Accountant / Finance |
| Inter-company invoicing | Each operating company |
| PAYE/NIC submission (RTI) | Payroll |
| VAT return (quarterly) | Accountant |
| KPI reporting | Operations |

### As Needed

| Event | Action |
|---|---|
| New employee joins | Auto-enrolment assessment, EMI grant (if applicable) |
| Material contract | Check against reserved matters thresholds |
| Founder wants to transfer shares | Pre-emption process per SHA |
| Dispute arises | Follow escalation ladder in SHA |
| Approaching SME thresholds | Prepare transfer pricing documentation |

## Critical Path

```
Week 1-2:   Engage solicitor + accountant
Week 2-4:   Negotiate and agree heads of terms
Week 4-10:  Legal drafting (SHA, Articles, inter-company agreements)
Week 10-12: Incorporate at Companies House, HMRC registrations
Week 12-14: Execute inter-company agreements, set up invoicing
Week 14+:   JV Co begins trading
```

**Minimum realistic timeline: 10–14 weeks from engaging solicitors to trading.**

Speed can be improved if:
- Founders pre-agree most heads of terms before engaging solicitors
- Solicitor uses established JV precedents (not drafting from scratch)
- Both founders are responsive to review cycles
