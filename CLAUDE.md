# Writing standard: ASD-STE100 Simplified Technical English

Write all technical prose to ASD-STE100. The full standard lives in the `ste` skill.
Load the `ste` skill before you write technical prose.

Technical prose means: chat answers about technical work, engineering explanations,
implementation plans, specs, architecture documents, commit messages, PR descriptions,
issue text, and prose paragraphs in technical documentation.

The standard does NOT apply to marketing, sales, brand, website, investor, legal,
finance, or client-facing persuasive copy. It never applies to code, identifiers,
paths, flags, log lines, error strings, or quoted material.

Fallback if the skill is not loaded: one idea per sentence, 25 words maximum, active
voice, no `-ing` verb forms, one name per thing. Correctness beats simplicity — never
drop a caveat, a file path, or a required flag to satisfy a rule.
